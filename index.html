01
ICP & account scoring

Ideal Customer Profile scoring model

Cohesity · Director, Sales Operations
Live prototype↗

Designed to replace a previously quoted $100K+ external consulting engagement by building the same capability entirely in-house. Synthesizes firmographic and technographic signals from D&B Hoovers, HG Insights, ZoomInfo, and 6Sense into a single composite score for every account in the addressable market.

Built using Claude Code via the CLI, managed locally in a Git repository. A full logistic regression was run against four years of closed-won and closed-lost opportunities to calibrate the dimension weights — the model reflects observed revenue outcomes, not assumptions.

# ICP Score Composite icp_score = ( firmographic_fit * 0.25 # size, industry, geo + technographic_fit * 0.30 # relevant tech stack + intent_signal * 0.20 # 6Sense, ZoomInfo + growth_trajectory * 0.15 # headcount / revenue + competitive_install* 0.10 # displacement )
